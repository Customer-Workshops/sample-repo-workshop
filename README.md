# Rock Paper Scissors Game

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

### How to play

1. Open `index.html` in any modern web browser (double-click the file, or right-click and choose "Open with" your browser).
2. Click one of the ✊ (Rock), ✋ (Paper), or ✌️ (Scissors) buttons to make your move.
3. The computer will randomly pick its own move, and the result of the round (win, lose, or tie) will be shown along with both picks.
4. Your score and the computer's score update automatically after each round.
5. Click **Reset Game** at any time to clear the scores and start over.

### Files

- `index.html` – the game's markup/structure.
- `style.css` – styling for the game board, buttons, and scoreboard.
- `script.js` – game logic (random computer choice, win/lose/tie rules) wired up to the buttons in `index.html`.

No build step or dependencies are required — just open `index.html` in a browser to play.
